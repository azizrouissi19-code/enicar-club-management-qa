    Comment partager avec l'équipe
    1. Préparez la semaine ici : objectifs de M. Jaidi, tâches de chacun, bilan. Tout est enregistré dans ce navigateur, et la vue d'équipe ouverte dans un autre onglet se met à jour.
    2. Cliquez sur « Exporter donnees.js » et remplacez le fichier suivi/donnees.js du dépôt par celui téléchargé.
    3. git add suivi/donnees.js, git commit -m "suivi : semaine …", git push. Bouchahda et Missaoui font git pull et ouvrent suivi/index.html.
